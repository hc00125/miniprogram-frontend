# 钻石标价与支付模型

## 固定换算

- 后端真实账务单位：人民币 Decimal。
- 前端商品、服务、订单和续单展示单位：整数钻石。
- 固定比例：人民币 1 元 = 10 钻石。
- 可消费金额必须能换算为整数钻石；不允许出现小数钻石。

## 两种订单支付方式

1. **可用钻石支付**：从用户钻石钱包扣除对应数量。后端实际扣除人民币等值余额。
2. **微信即时支付**：用户通过微信购买当前订单所需的等额钻石，并立即用于该订单；这部分钻石不会重复进入可用钻石钱包。

用户不必事先充值。两种支付方式同时保留，暂不支持“部分钱包钻石 + 部分微信”的混合支付。

## 充值档位

| 实付人民币 | 到账钻石 |
| ---: | ---: |
| 10 元 | 100 |
| 30 元 | 300 |
| 50 元 | 500 |
| 100 元 | 1,000 |
| 200 元 | 2,000 |
| 500 元 | 5,000 |
| 1,000 元 | 10,000 |

充值商品由后端 `RechargeProduct` 独立维护，并在微信小程序虚拟支付后台创建对应虚拟道具；不进入普通陪玩服务商城。

## 钻石类型

- **可用钻石**：充值获得，可用于支付，退款时可能退回。
- **成长钻石**：订单完成后产生，只用于 VIP 等级，不可支付或提现。

## 展示边界

- 商品、购物车、结算、订单、续单、钱包流水：显示整数钻石。
- 充值页：同时显示到账钻石和微信实际支付人民币。
- 微信即时支付页：订单仍以钻石标价，同时说明本次微信实际扣款。
- 陪玩收益中心继续使用鱼干；罚款等运营结算按原规则展示，不与用户消费钻石混用。

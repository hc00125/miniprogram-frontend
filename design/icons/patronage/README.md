# Patronage icons

The crown, pause, and play SVG masters are from [Material Design Icons by Pictogrammers](https://github.com/Templarian/MaterialDesign/tree/master/svg), under the Apache License 2.0 (see LICENSE.txt).

The shipped transparent PNGs in `static/icons/patronage/` use these original paths, colored gold (#B5812C), rendered at 96 × 96 for WeChat image compatibility. The SVG masters are not shipped to the mini-program.
